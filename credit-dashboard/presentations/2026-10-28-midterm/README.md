## 発表に使うファイル

- `midterm-2026-10-28.pptx`：編集可能なPowerPoint。本編11枚・質疑用補足3枚。本文、図、表は編集可能な図形・テキストで構成し、実画面だけ画像として埋め込む。
- `midterm-2026-10-28.pdf`：同じ14枚の閲覧・配布用。日本語フォントを埋め込み、本文を検索・選択できるPDF。
- `speaker-notes.md`：本編10分を想定した発表原稿と時間配分。PowerPointの各スライドの発表者ノートにも同じ原稿と根拠を記載する。
- `overview.png`：全14枚の一覧。`previews/`に各ページの画像も置く。
- `validation.json`：14枚・本編600秒、全スライドのノート、PPTXのXML整合性・編集可能な本文、PDFの文字取得、ページ内配置、個人情報パターンの検査結果。

通常の発表は11枚目で終了し、12〜14枚目は質問に応じて使う。配布資料に従い、発表10分・質疑5分・指摘を整理する5分を想定する。原稿の時間配分は目安なので、本番前に通し練習で調整する。

## 根拠と表現上の境界

要件は`docs/requirements.md`、設計は`docs/architecture.md`、APIは`docs/data-contract.md`と推薦APIの文書、テスト結果は`docs/testing.md`第25節を参照した。各スライドの発表者ノートに対応する文書を記録している。

- 自動テスト364件・ブラウザー75項目は、2026-10-28の検証記録による。今回のスライド作成のためにアプリケーションのテストを追加した件数ではない。
- 完全な第三者による独立実装や、学生を対象とした体系的な使い勝手評価を実施したとは表現しない。
- 学務判定は参考情報。公式規則との違いと、現在の対応範囲は補足B・発表者ノートへ明記した。
- 教養探索はルールに基づく照合であり、生成AIによる判定や成績予測ではない。候補同士を組み合わせた履修計画、順位付け、履修許可の保証は含めない。

## 個人情報

画面は新しいブラウザーセッションで、リポジトリの架空CSVとメモリ生成した架空履修表だけを使って撮影した。実在する学生のCSV・名前・番号・成績は参照していない。撮影時の外部オリジンへの通信は遮断した。

`assets/overview.png`は架空の卒業確認例、`assets/timetable.png`と`assets/recommendation.png`は架空の履修表・成績で確認した候補である。`assets/first-year.png`は差し替え用の架空1年生画面として保持する。

原本の学生CSV、授業資料PDF、サーバーのログ、CSV本文、API応答本文は同梱していない。PowerPointとPDFの作成者は汎用の「単位ノート」とし、個人名や個人メール、利用者固有の絶対パスは埋め込まない。

## 編集・再生成

通常の修正はPowerPointから行える。プログラムから作り直す場合は、`build_slides.py`の本文・図形・原稿を編集する。`slide-content.json`は生成された内容一覧であり、編集の正本ではない。

作成用の依存は`requirements-authoring.txt`を使う。Webアプリ本体の依存・バックエンド・APIは変更していない。Windowsのメイリオを利用し、`CREDIT_SLIDE_FONT_DIR`で`meiryo.ttc`と`meiryob.ttc`のある場所を指定できる。配布PDFには必要な文字のフォントを埋め込み、PowerPointには書体名だけを指定する。

```bash
python -m pip install -r requirements-authoring.txt
python build_slides.py
```

生成時に14枚・本編600秒・文字の枠内収容・要素のページ内収容を検査する。生成後はPDFの全ページを画像化し、文字化け・配置・画面例を確認する。発表資料の生成だけを目的とし、アプリケーションを変更しない。

作成時はPDFの全14ページを目視し、不自然な改行を調整して再生成した。PPTXを再読み込みし、本文と発表者ノートが生成内容に一致すること、93個のXML・関連パーツが解析できること、埋め込まれた画像が確認済みの架空画面だけであることを検証した。PPTXは約369KB、PDFは約542KB。
