# 開発ロードマップ

## Milestone 1: 安全なCSVアップロードと表示

**状態: 完了（2026-10-22）**

- `POST /api/v1/reports` の追加
- CSVをメモリ上で解析し、原本を保存しない
- ファイルサイズ・形式・必須列の検証
- フロントエンドのファイル選択、送信、進捗、再試行
- 既存の集計・科目一覧をアップロード結果から描画
- 氏名、学籍番号、所属、学年を画面に表示
- 可変数の科目行をファイル終端まで解析
- 合格かつ単位数確定の科目だけを取得単位へ算入
- 個人情報を含まないログ
- API・画面・非保存性のテスト

完了条件は `requirements.md` のリリース1受け入れ条件をすべて満たすこと。

## Milestone 2: 2025年度カリキュラム分類

- 教養系の細区分を公式規程に沿って分類
- 専門基礎・専門応用とA〜Eを正規化
- 不明・曖昧な科目を警告
- 科目分類規則のデータ化と出典ページの保持

## Milestone 3: 進級・卒業要件判定

- 第2年次進級条件
- 第4年次進級条件
- 卒業資格条件
- `satisfied` / `not_satisfied` / `unknown` の三値判定
- 不足単位と個別必修不足の表示
- 判定根拠と公式資料リンクの表示

## Milestone 4: GPA・成績分析

- 得点、評価、GPの入力品質確認
- 公式式による学期GPA・累積GPA
- 科目群、年度、学期ごとの傾向
- 再履修・取消・認定科目の扱いを確定

## Milestone 5: 履修候補探索

- 2025年度標準課程表の科目マスター
- 未充足枠を満たす候補科目
- 前提科目、開講時期、重複、取得済みの考慮
- 「要件上の候補」と「推奨」を区別

## Milestone 6: 予測機能の検討

- 予測目的と有用性の検証
- 学習データの合法性・同意・偏りの確認
- 不確実性と説明方法の設計
- 進級・卒業の確定判定とは分離

## 将来の横断的な拡張

- 2年次以外の学年
- 別の入学年度・プログラムを規則プロファイルとして追加
- サーバー公開時の利用者認証
- 要望に応じた分析・表示機能。ただし既存APIと規則の後方互換性を維持する
