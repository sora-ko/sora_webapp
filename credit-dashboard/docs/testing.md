# テスト方針

## 1. 原則

- 実在する学生のCSVをリポジトリへ追加しない。
- テストデータは架空の氏名、在籍番号、科目結果で作成する。
- 公式規則の境界値をテスト名と期待値から追跡できるようにする。
- 分類不能な入力に対し、都合のよい分類をしないことをテストする。

## 2. CSV解析テスト

- UTF-8、UTF-8 BOM、CP932
- 前置き学生情報あり・なし
- 必須列不足、重複列、列順変更、余分な列
- 空ファイル、空行、改行コード差
- 引用符、カンマを含む科目名
- 整数・小数・空・負数・非数の単位
- 合、否、空欄、未知の合否
- No.重複、科目名空欄、科目区分空欄
- 同名科目で開講番号が異なるケース
- 科目行が0件、1件、多数のケース。サンプルの行数へ依存しない
- 見出し以降の空行と、科目ではない非空行
- `合否=合` だが単位数が空欄の科目を取得済みに数えない

## 3. アップロードAPIテスト

- 正常な1ファイル
- ファイルなし、複数ファイル
- 0バイト、上限ちょうど、上限超過
- 偽の拡張子・MIME type
- 解析エラーのHTTPステータスとエラーコード
- レスポンスのschema_version
- 連続する2リクエストのデータが混ざらない
- CSV本文と個人情報がログに出ない
- プロジェクト、一時ディレクトリ、DBへファイルを作らない

## 4. 画面テスト

- ファイル未選択時の操作
- 送信中の多重送信防止
- 成功、警告、エラーの表示
- 再アップロード時に前回結果を適切に破棄
- キーボードだけでの操作
- 画面幅320px程度で主要情報を閲覧可能
- 氏名・在籍番号の表示方針
- 氏名・学籍番号を表示しても、ログとブラウザー永続ストレージには残らない
- APIが不正なJSONを返した場合の安全なエラー

## 5. 学務規則テスト

判定機能の実装時に追加する。

### 第2年次進級

- 総計31 / 32 / 33単位
- 指定5科目が3 / 4 / 5単位
- D科目を含めると32だが、除外すると31となるケース
- 在学期間不明は `unknown`

### 第4年次進級

- 総計103 / 104 / 105単位
- 専門66、教養32、共通枠6の各境界
- 専門基礎Bの余剰を専門応用Bへ算入
- E科目6単位までは算入し、7単位目を算入しない
- D科目を算入しない
- 1科目を複数枠へ二重計上しない

### 卒業

- 総計123 / 124 / 125単位
- 専門82、教養36、共通枠6の各境界
- 教養の必修13、選択必修12、選択11の各境界
- 専門基礎B余剰の振替
- 区分合計は満たすが個別必修が不足するケース
- 在学期間不明は `unknown`

## 6. 回帰テスト

- 公式CSV形式の変更を確認したら、匿名化した最小再現データを追加する。
- バグ修正には、修正前に失敗し修正後に成功するテストを追加する。
- 規則改訂時は既存年度の期待値を変更せず、新しい規則セットとテストを追加する。
