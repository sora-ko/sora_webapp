# 学務判定ルール（2025年度入学・知能情報システムプログラム）

## 1. 目的と注意

この文書は、進級・卒業要件判定の根拠と、機械判定に必要な規則を整理する。
MVPの基準対象は、2025年度（令和7年度）入学で現在2年次の新潟大学工学部・知能情報システムプログラム所属学生である。
規則は現在学年から分離し、同じ入学年度の1〜4年次について、第2・第4年次進級と卒業確認の表示を切り替える。別の入学年度・プログラムには新しい規則プロファイルが必要になる。

2026-10-26に利用者が指定したMVP方針では、留学生向け代替規則・早期卒業・他大学の単位認定は対象外、夜間主科目は含まれない前提とする。専門科目一覧に一致しない既知の専門系科目を教養の選択へ分類し、工学リテラシー入門の分野名を区別しない。この2点は公式規則の解釈とは別の製品方針であり、同検証記録第13節と画面の注意書きに明記する。

公式資料の参照箇所、表の結合セル、判断理由、現行実装との差異は、`docs/rule-verification-2025-sis.md`に監査記録として残す。この文書に記載した公式規則と現在の集計動作が異なる箇所は、修正完了まで同一視しない。

本アプリケーションの結果は参考情報であり、大学による正式な判定ではない。資料の解釈に疑義がある場合は、工学部の担当窓口または担当教員への確認を優先する。

## 3. 科目コード体系

工学部専門系科目では、次の種類を用いる。

| 種類 | コード |
| --- | --- |
| 必修科目 | A |
| 選択必修科目 | B |
| 選択科目 | C |
| 特殊選択科目 | D |
| 自由科目 | E |

CSVの「必選区分」だけでは科目群を一意に決められない。`科目区分` と `必選区分` の組合せから、専門基礎B、専門応用Aなどへ正規化する必要がある。

## 4. 第2年次進級

次の条件をすべて満たす。

1. 工学部に通算1年以上在学している。
2. 教養系科目と学部専門系科目を合計32単位以上修得している。
3. 次の5科目群から合計4単位以上を修得している。
   - 総合工学概論
   - 総合技術科学演習
   - 技術者の心がまえ
   - 知的財産概論
   - 情報セキュリティ概論
4. D科目は32単位に含めない。

CSVだけでは本来の在学期間を確定できない可能性があるため、単位条件と在学期間条件は別々に評価する。MVPでは利用者の指定により、留年・編入がなく学年と在学年数が一致すると仮定する。

現在のアプリケーションでは第2年次進級の基本条件を評価する。在学期間は利用者の任意入力を優先し、未入力ならCSVの学年を前記のMVP前提で使用する。どちらも得られない場合だけ当該条件と総合結果を`unknown`にする。科目名末尾のCSV表示記号`◆`は、規則プロファイルに明示した場合だけ照合時に除去する。専門区分は、工学科共通・分野導入を含む対象プログラムの科目マスターを優先する。

第4年次進級・卒業資格は確認済みの分類別単位を表示する。専門・教養の共通6単位は、各区分の最低単位を超えた確認済み単位の合計として評価する。専門基礎Bの余剰振替は公式表の備考に従って決定的に配賦する。卒業では専門系必修16科目も個別確認し、表示した全条件を満たせば総合`satisfied`とする。確定した不足があれば`not_satisfied`、それ以外で分類不能科目や未確定情報が結論へ影響するときは`unknown`とする。

## 5. 第4年次進級

工学部に通算3年以上在学し、3年次末までに次の最低単位数を修得する。

### 5.1 知能情報システムプログラムの最低単位数

| 区分 | 最低単位数 |
| --- | ---: |
| 専門基礎科目群 A科目 | 0（設定なし） |
| 専門基礎科目群 B科目 | 10 |
| 専門応用科目群 A科目 | 19 |
| 専門応用科目群 B科目 | 26 |
| 専門応用科目群 B・C・E科目から | 11 |
| 学部専門系科目 計 | 66 |
| 教養系科目 計 | 32 |
| 学部専門系科目または教養系科目 | 6 |
| 総計 | 104 |

教養系32単位の内訳は、必修13、選択必修12、選択7である。

### 5.2 算入規則

- E科目は最大6単位まで第4年次進級要件に算入できる。
- D科目は第4年次進級要件に算入できない。
- 専門基礎科目群B科目の10単位を超える単位は、専門応用科目群B科目として算入できる。
- 「専門応用B・C・Eから11単位」は、専門基礎Bの10単位と専門応用Bの26単位へ先に充当した後の残余から数える。したがって、専門応用Bの同じ26単位を11単位枠へ重ねて数えない。
- 専門応用Bの確認値は `専門基礎B＋専門応用B−専門基礎Bへの充当10`、B・C・E残余枠は `専門基礎B＋専門応用B/C/E−基礎Bへの充当10−応用Bへの充当26` とする。各差は0未満にしない。
- 「学部専門系科目または教養系科目」6単位は、`max(専門計−専門最低, 0) + max(教養計−教養最低, 0)`で評価する。専門・教養は排他的に分類し、二重計上しない。
- 編入学生には別規則があるため、通常入学者向け判定と混在させない。

## 6. 卒業資格

工学部に通算4年以上在学し、次の最低単位数を修得する。

| 区分 | 最低単位数 |
| --- | ---: |
| 専門基礎科目群 A科目 | 0（設定なし） |
| 専門基礎科目群 B科目 | 10 |
| 専門応用科目群 A科目 | 27 |
| 専門応用科目群 B科目 | 28 |
| 専門応用科目群 B・C・D・E科目から | 17 |
| 学部専門系科目 計 | 82 |
| 教養系科目 計 | 36 |
| 学部専門系科目または教養系科目 | 6 |
| 総計 | 124 |

### 6.1 教養系36単位

規程別表第1では、教養系科目の内訳を次の合計としている。

| 区分 | 最低単位数 |
| --- | ---: |
| 必修 | 13 |
| 選択必修 | 12 |
| 選択 | 11 |
| 計 | 36 |

必修13単位には、大学学習法、英語、初修外国語、健康・スポーツ、情報リテラシー、人文社会・教育科学の指定単位が含まれる。細区分ごとの算入は規程別表第1を正本とする。

アプリケーションでは、教養系のCSV「必選区分」を卒業要件表の必修・選択必修・選択へ直接対応させない。教養系では同じ欄が卒業要件上の枠と一致しないため、「科目区分」と、規程が指定する科目名を使って次の順に配賦する。専門系のA〜E判定では、引き続き「科目区分」と「必選区分」の組合せを使う。

| 細区分 | 充当する最低単位 |
| --- | ---: |
| 大学学習法 | 必修2 |
| 英語 | 必修2 |
| 初修外国語 | 必修2 |
| 健康スポーツ科学実習Ⅰ | 必修1 |
| エンジニアのためのデータサイエンス入門 | 必修2 |
| 人文社会・教育科学 | 必修4 |
| 人文社会・教育科学または新潟大学個性化科目 | 選択必修2 |
| 情報リテラシー（必修指定科目を除く）、自然系共通専門基礎、自然科学 | 選択必修10 |

まず大学学習法2、英語2、初修外国語2、健康スポーツ1、情報リテラシー2、人文社会・教育科学4へ充当する。次に、人文社会・教育科学と新潟大学個性化科目の合計から、先に人文社会・教育科学へ充当した分を除いた残余を選択必修2単位へ充当する。情報リテラシーの残余、自然系共通専門基礎、自然科学の合計から、別の選択必修10単位へ充当する。最後に、全教養系単位からこれらの枠へ実際に充当した単位を差し引き、残余を選択11単位（第4年次進級では7単位）として数える。この順序により、同じ単位を複数の最低枠へ二重計上しない。

2026-10-26に、選択必修10単位の対象へ自然科学と公式の単独「情報リテラシー」を追加した。必修指定のデータサイエンス入門はこの10単位から除外し、余剰だけを選択残余へ回す。

大学学習法のMVP判定では、教養科目の正規化名に「工学リテラシー入門」が含まれるかを確認する。半角・全角括弧内の分野名は問わない。単に大学学習法区分に入るだけでは、この必修2単位へ算入しない。

### 6.2 算入規則

- 専門基礎科目群B科目の10単位を超える単位は、専門応用科目群B科目として算入できる。
- 「専門応用B・C・D・Eから17単位」は、専門基礎Bの10単位と専門応用Bの28単位へ先に充当した後の残余から数える。同じB単位を28単位枠と17単位枠へ重ねて数えない。
- 卒業資格におけるE科目単位数の上限は、細則別表第2で定めないと明記されている。
- 各科目は1つの必要枠へだけ配賦し、総計で二重計上しない。
- 必修科目の個別修得状況も確認する。区分合計だけ満たしても、必修科目が不足していれば充足としない。

### 6.3 全要件に関係する例外

- 夜間主科目は、第2・第4年次進級および卒業の要件単位へ含めない。
- 所属プログラム以外のA・B・C科目は、原則として所属プログラムの専門応用Cとして扱う。同名の専門基礎科目には例外がある。
- 学部専門系科目以外の科目を修得した場合、工学部では教養系科目とみなす。ただし、CSVだけで非専門科目と確定できない値を便宜的に教養へ変換しない。
- 外国人留学生は、日本語を4単位まで初修外国語へ、日本事情を内容に応じ8単位まで自然系共通専門基礎または人文社会・教育科学へ代替できる。
- 3年次編入学生と早期卒業には別の基準があるため、通常入学者向け判定へ混在させない。

上記は公式規則として保持する。MVPでは利用者の指定により、夜間主がない前提、留学生代替と早期卒業は対象外とし、他プログラム専門科目は公式のC読替えに代えて教養の選択へ分類する。前提に当てはまるかの自動判定は行わない。他大学単位は既知の公式ラベル「単位互換協定に基づき修得した他大学開設科目」だけを要件から除外し、未知表記は推測しない。

### 6.4 科目マスターとの比較

`rules/niigata/engineering/smart-information-systems/2025/course-catalog.json`に、対象専門科目83件と、科目群・A〜E・公式単位数・標準年次・根拠頁・別名を保持する。開講番号は公式資料で確定できないため`null`とし、照合には公式科目名と明示した別名を使う。全半角・ローマ数字・空白の差を照合時に吸収する。

CSVの既知専門区分に対してのみこの一覧照合を行う。既知の教養区分は維持し、未知区分は`unknown`のままとする。一覧に一致した場合はマスターの科目群とA〜Eを採用する。一致しない専門科目はMVP方針で「対象専門科目一覧外」の教養へ分類し、必修・選択必修の細枠には使わず、選択残余・教養合計・総計へ数える。

一覧の公式単位数をCSVへ代入しない。算入対象は引き続き`合否=合`かつ単位数が確定した行だけである。開講番号が異なる行は、同じ科目マスターIDや科目名でも別科目として数える。

### 6.5 卒業の個別必修科目確認

根拠は工学科共通の必修科目表（冊子8頁／PDF12頁）、知能情報システムの必修科目表（冊子12頁／PDF16頁）および標準課程表のA列（冊子39頁／PDF43頁）。科目マスターの`required_for`に`graduation`を持つ16科目、合計27単位を確認対象とする。

`required_courses`条件は各科目を名前と明示別名で照合し、合格かつ必要単位数以上の有効な修得行を確認する。存在しない、不合格のみ、必要単位未達の場合は`not_satisfied`とする。合否、単位数、専門分類が未確定の候補により結果が変わり得る場合は`unknown`とし、有効な修得行が別に確認できれば`satisfied`とする。

異なる開講番号による同名科目の修得は、既定のMVP方針に従い全体単位へ別々に算入できる。しかし、同じ必修を複数回修得しても別の必修には置き換えない。1科目の必要単位を下回る複数行を足して必修修得とはしない。科目ごとの確認単位は説明用で、総計や配賦済み単位へ再加算しない。

個別必修を含む全条件が充足なら卒業総合`satisfied`、確定した未充足があれば`not_satisfied`、それ以外に未確定情報があれば`unknown`とする。実装未接続を理由に卒業総合を常時`unknown`へ固定する処理は解除した。

## 7. GPA

公式資料の式は次のとおり。

- 60点未満のGPは0。
- それ以外のGPは `(得点 - 50) / 10`。
- GPAは `Σ(履修登録した各科目の単位数 × GP) / 履修登録した各科目の単位数の総和`。
- 累積GPAも入学後の全履修登録科目について同様に算出する。

現在のサンプルCSVには得点・評価・GPの列があるが、空欄を含む。GPA機能は、大学側CSVの値と再履修・履修取消等の扱いを実例で確認してから実装する。

## 8. 判定結果の三値

各規則の判定結果は、単純な真偽ではなく次の三値とする。

- `satisfied`: 必要な入力が揃い、条件を満たす。
- `not_satisfied`: 必要な入力が揃い、条件を満たさない。
- `unknown`: 在学期間、科目分類、単位認定等の情報不足により確定できない。

`unknown` を `not_satisfied` に読み替えてはならない。

単位集計の入力には、CSV上で合格かつ単位数確定と確認できた科目だけを使用する。合否空欄、未知の合否、または単位数空欄の科目を進級・卒業要件へ算入しない。

## 9. 対応範囲を広げるときの要確認事項

- CSV上の認定科目、他大学科目、自由科目、特殊選択科目の実際の表記。
- 他大学の単位認定はMVP対象外。未確認表記へ対応する場合は、改めて公式な認定規則とCSV形式を確認する。
- MVPでは開講番号の異なる再履修を別科目として扱う。同等科目の名寄せは将来要望が出た場合に検討する。
- 取得年度が空欄の合格科目を進級時点判定に含めてよいか。
- 未取得年度の開講情報や、候補の順位付け・先修条件・履修許可へ対応するときの根拠。現在の教養探索は2026年度の公式開設一覧を使い、卒業条件を変える機能ではない。
- 夜間主や留学生代替を将来対象に含める場合の入力情報。
- 他プログラム科目について公式C読替えを将来実装する場合の、所属学生向けCSV区分の意味。
- 学部専門系以外の科目を教養系とみなすために必要な科目マスター上の根拠。
