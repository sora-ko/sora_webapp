# localhostアップロード確認記録（2026-10-26）

この文書は当日の確認記録として保持する。2026-10-27時点の実装・再検証結果は[テスト方針](testing.md)、初回の架空CSV復元は[引き継ぎ手順](handoff.md)を参照する。

## 対象と方法

- 稼働中の`http://127.0.0.1:8000/api/v1/reports`へ、実際のHTTP multipartリクエストで架空CSVを送信した。
- 対象は新潟大学工学部・知能情報システムプログラム・2025年度入学の規則プロファイル。
- 原則として前置き4行・19列・CP932・CRLFで生成し、形式差のケースだけ文字コード・改行・列順を変更した。
- 使用元は`examples/first-year-sample.csv`と`examples/graduation-sample-original-format.csv`のみ。実在する学生CSVは参照していない。
- ケースごとのCSVはメモリ上で加工し、ファイルやDBへ保存していない。ログはケース名・成否・HTTPステータス・総合判定またはエラーコードだけで、学生情報、CSV本文、科目名と成績の組合せは記録しない。
- 配信中のHTML・JavaScript・CSSを作業中のファイルとハッシュ照合し、すべて一致した。以前発生した「起動中コンテナーだけ旧版」の状態でないことも確認した。

利用者の了承により、今回はAPI応答の表示対象・数値・判定・説明文を確認対象とした。ブラウザーの実描画、画面幅によるレイアウト、クリック・ドラッグ操作は確認していない。画面で使用する判定文言は`satisfied`が「条件を満たす」、`not_satisfied`が「条件を満たさない」、`unknown`が「判定不能」である。

## 結果

32ケースすべて期待どおり。既存の自動テスト141件も成功した。今回の確認で、アプリ本体や学務規則の修正を必要とする問題は見つからなかった。

| 確認内容 | 件数 | 確認した結果 |
| --- | ---: | --- |
| 1年生・第2年次進級の31／32／33単位境界 | 3 | D科目を除く31単位は未充足、32・33単位は充足。表示は第2年次進級＋卒業 |
| 2・3・4年生の表示対象と在学期間 | 3 | 2・3年は第4年次進級＋卒業、4年は卒業だけ。必要単位を持っていても在学期間不足は未充足 |
| 卒業の123／125単位境界 | 2 | 123単位は未充足、125単位は充足。124単位の充足は4年生ケースで確認 |
| 必修科目の代替不可・不合格・未確定 | 4 | 同名別コードの別必修への置換や不合格は未充足。合否未確定・単位数不明は判定不能 |
| 学年欠落 | 1 | 全3要件を表示し、在学期間が確認できないため判定不能 |
| 人文社会と個性化科目の配賦 | 1 | 人文社会6単位の場合、必修4を先に充当し、残り2を選択必修へ。個性化科目2単位の算入は1年生・4年生の基本ケースでも確認 |
| 自然科学のみ／情報・自然系基礎・自然科学の混在 | 2 | どちらも選択必修の対象へ算入。必要10単位の充当後に残余を選択枠へ回す |
| データサイエンス入門の二重計上防止 | 1 | 自然系選択必修の候補8単位に必修データサイエンス2単位を加算せず、総計124単位でも当該条件は未充足 |
| 専門・教養の超過を合算 | 1 | 専門85・教養39の超過3＋3で共通6単位を充足 |
| 分類不明の影響あり／最低条件充足後の余分な不明科目 | 2 | 判定に影響する場合だけ判定不能。既知の科目だけですべて充足していれば充足を維持 |
| 専門一覧外の科目／既知の他大学単位ラベル | 2 | 前者はMVP方針で教養の選択へ。後者は取得済み表示に残すが学務要件から除外 |
| UTF-8 BOM＋CRLF／UTF-8 BOMなし＋LF | 2 | CP932の基本ケースと同じ卒業充足結果 |
| 成績列の順序を逆転 | 1 | 見出し名で読み取り、同じ卒業充足結果 |
| 科目行数を83行へ増加 | 1 | 末尾まで読み取り、149単位・83科目を返す |
| 空CSV・必須列欠落・単位数不正・No.重複・文字コード不正・5 MiB超過 | 6 | 各ケースで想定したHTTPステータス、機械可読コード、表示用メッセージを返す |

正常応答では、学年別の表示対象が過不足なく一致すること、各条件の表示名・説明が存在すること、判定値が三値のいずれかであることも検証した。「すべての条件が充足なのに総合が判定不能」の回帰も検出する。

### 卒業充足ケースの内訳

- 学年4年、在学期間4年、総計124単位（専門88・教養36）。
- 卒業資格条件は20項目すべて充足。専門系個別必修は16／16科目。
- 専門または教養の超過単位は6／6単位。
- 教養の選択枠は11／11単位。自然系選択必修の確認済み21単位は対象候補の総数であり、最低枠10単位を充当後の残余は選択枠へ回す。候補総数21と選択枠11を別々の取得単位として足し合わせない。
- 警告0件。卒業総合は`satisfied`。

## 再実行

アプリを起動した状態で、プロジェクト直下から実行する。追加パッケージは不要（Python標準ライブラリのみ）。

```bash
.venv/bin/python scripts/check_localhost_uploads.py
```

`--base-url http://127.0.0.1:別ポート`でローカルポートを変更できる。誤送信を防ぐため、送信先は`localhost`・`127.0.0.1`・`::1`のHTTPに限定しており、任意のCSVパスを受け取る機能はない。

配信中の画面ファイルが作業中のコードと異なると、結果を混同しないようエラーにする。Docker利用時は必要に応じて利用者が再ビルドする。この確認スクリプト自身はコンテナーを再ビルド・再起動しない。
