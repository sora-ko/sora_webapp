# 用語集

- **ELF**: Linux等で使われる実行ファイル・オブジェクトファイルの形式。本プロジェクトでは主にコンパイル済みLinux実行ファイルを指す。
- **GDB**: GNU Debugger。対象プログラムの実行を制御し、レジスタやメモリ等を調査する。
- **GDB/MI**: GDBを機械的に制御するためのインターフェース。アプリケーションが応答や状態通知を解析する。
- **pwndbg**: GDBを拡張してpwn向けの解析を支援するツール。
- **PIE**: Position Independent Executable。実行時のロードアドレスが変化する構成に関係する。
- **RSP**: x86-64のスタックポインタレジスタ。
- **RBP**: x86-64の汎用レジスタ。慣例的にフレームポインタとして使われることがあるが、必ずそうなるわけではない。
- **セッション**: 1つのデバッグ対象と、それに対応するGDB、対象プロセス、作業領域をまとめた管理単位。
- **Inferior**: GDBがデバッグするプログラム／プロセスを指すGDB用語。
- **Spike**: 実装の不確実性を検証するための、小さく使い捨て可能な技術実験。
- **ADR**: Architecture Decision Record。設計判断、理由、代替案、影響を記録する文書。
