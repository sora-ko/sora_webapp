# 技術検証ログ

設計上の不確実性を小さなプログラムで検証し、結果をこのディレクトリに保存する。

検証記録テンプレート:

```markdown
# EXP-NNN: タイトル

- 日付:
- 環境:
- 仮説:
- 手順:
- 結果:
- 結論:
- 影響する設計文書:
- 未解決事項:
```

最初に検証する候補:

1. GDB/MIでの起動、停止、ステップ実行、レジスタ・メモリ取得
2. GDB制御チャネルと対象ELFのstdin/stdout/stderrの分離
3. WSLバックエンドとWindowsブラウザのlocalhost接続
4. ELFアップロードと専用作業ディレクトリ保存
5. シンボルのないELF・PIE・動的リンクELFの初期動作
