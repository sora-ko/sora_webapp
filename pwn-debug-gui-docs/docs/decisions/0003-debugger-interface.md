# ADR-0003: GDBを基本デバッガーとしpwndbgを拡張扱いにする

- 状態: 合意済み（GDB/MI採用の細部はPoCで確認）
- 日付: 2026-10-09

## 背景

利用者は現在pwndbgを使用しているが、アプリケーションのコア機能を特定の拡張に依存させず、AIが理解・拡張しやすい構造にすることを重視している。

## 決定

GDBを基本デバッガーとし、pwndbgはオプションの追加機能として扱う。GDB/MIを主要な機械向け通信インターフェースの候補とする。

## 理由

- 基本デバッグ機能を拡張機能から分離できる。
- pwndbgの人間向け出力形式を画面ロジックの中心にしなくてよい。
- 共通データモデルを介して、将来の拡張やUI変更を容易にできる。

## 影響

GDB/MIの応答解析、非同期イベント、エラー・停止状態を扱う必要がある。pwndbg独自の機能が必要な場合は、オプションのアダプターまたは解析サービスとして設計する。
