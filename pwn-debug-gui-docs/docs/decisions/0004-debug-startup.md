# ADR-0004: 通常起動し、利用者が停止位置を指定する

- 状態: 合意済み
- 日付: 2026-10-09

## 決定

基本フローでは、利用者がブレークポイントを設定して実行し、必要な位置で停止させる。初期版からエントリポイントや`main`で必ず自動停止する仕様にはしない。

## 理由

- 基本的なGDBの操作モデルを学びやすい。
- 実行開始位置の強制を避け、利用者の操作を優先できる。
- 自動停止オプションは後から追加できる。

## 影響

シンボルやソース情報がないELFでも使えるよう、命令アドレスによるブレークポイント指定を検討する。実行開始後に停止が必要な場合は、interrupt操作も用意する。

## 将来の拡張

エントリポイント停止、`main`停止、初期状態のスナップショットなどを追加できる。
