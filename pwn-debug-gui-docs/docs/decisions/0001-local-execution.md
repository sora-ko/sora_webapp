# ADR-0001: 初期版は利用者のローカル環境で実行する

- 状態: 合意済み
- 日付: 2026-10-09

## 背景

利用者は自身のUbuntu / WSLでデバッグできる構成を希望している。サーバー実行は将来的な構想だが、運用コストが大きい場合は断念する可能性がある。

## 決定

初期版ではバックエンド、GDB、対象ELFを利用者自身のUbuntu / WSL環境で実行する。ブラウザはそのローカルバックエンドを操作する。

## 理由

- サーバーの計算資源・運用コストを避けられる。
- 対象プログラムを利用者自身の環境で実行できる。
- 初期開発の構成と責務を単純に保てる。

## 影響

- 利用者は各自の環境にGDBなどの依存関係を用意する必要がある。
- Windows/WSL間のファイルパスやlocalhostアクセスを検証する必要がある。
- 初期版は原則としてループバックアドレスで公開する。

## 将来の再検討条件

複数利用者の実行を中央管理する必要性が明らかになり、運用・隔離コストを受け入れられる場合。
