# ADR-0005: 初期対象をコンパイル済みx86-64 Linux ELFに限定する

- 状態: 合意済み
- 日付: 2026-10-09

## 決定

初期版では、コンパイル済みのx86-64 Linux ELFをデバッグ対象とする。ソースコードからのコンパイルや他アーキテクチャ対応は初期版に含めない。

## 理由

- 初期スコープを明確にできる。
- 実際のpwn問題で配布されるELFを対象にできる。
- 開発期間を、デバッガー連携とメモリ可視化に集中できる。

## 影響

デバッグ情報がない場合は、逆アセンブルや実行時メモリ情報が中心となる。動的ライブラリ等の依存関係が不足している場合、初期版では原因を示して起動を失敗させる可能性がある。
